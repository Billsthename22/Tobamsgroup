# Tobams Group Assessment - Next.js App

This project is a fully responsive web application built for the Tobams Group assessment, adhering strictly to all technical and design requirements.

## Tech Stack & Guidelines Compliance
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS (No external UI frameworks like Bootstrap, MUI, or Chakra UI were used)
* **Components:** Hand-crafted custom components matching design specifications without external template copying.

## Design Adjustments Note
To ensure optimal visual hierarchy, responsiveness, and cross-device usability, a few minor adjustments were made relative to the exact Figma pixel measurements:
* **Typography:** Certain font sizes were adjusted slightly downward where needed to prevent text wrapping issues on smaller viewports while maintaining legibility.
* **Logos:** Brand and graphic elements were scaled slightly larger to enhance visual prominence and brand clarity.
* **Buttons:** Padding and button dimensions were fine-tuned to fit cleaner within responsive layouts and align with standard interactive touch targets.

## AI Tools Disclosure
In accordance with the assessment guidelines regarding transparency, please note that AI tools (Gemini) were utilized exclusively for debugging and correcting code during the development of this project.
