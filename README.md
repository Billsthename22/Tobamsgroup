# Tobams Group Assessment - Next.js App
This project is a fully responsive web application built for the Tobams Group assessment, adhering strictly to all technical and design requirements.

## Tech Stack & Guidelines Compliance
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS (No external UI frameworks like Bootstrap, MUI, or Chakra UI were used)
* **Components:** Hand-crafted custom components matching design specifications without external template copying.

## AI Tools Disclosure
In accordance with the assessment guidelines regarding transparency, please note that AI tools (Gemini) were utilized exclusively for debugging and correcting code during the development of this project.
